# Principles

These are the standing rules for every repository under [brandon-fox](https://github.com/brandon-fox), [First-ADE](https://github.com/First-ADE) and [vindicta-platform](https://github.com/vindicta-platform). They are the human-readable form of the axioms that CI enforces; where an axiom exists, it is named.

## 1. Open by default

Every personal project is public and MIT-licensed from its first commit. The license is a full grant: anyone may use, copy, modify and redistribute the work, for any purpose, commercial or not. Copyright and attribution stay with Brandon Fox. Private repositories hold secrets and personal data only, never code that is merely unfinished. (Axiom A8.)

## 2. Built in the open

Specifications, architecture decision records, feature files, issues and roadmaps are public alongside the code. The design record is part of the deliverable, and a project whose implementation is unscheduled still publishes its design.

## 3. Honest code

The first line of every README says what the thing is; the second says its real status. No claimed users, teams, adoption or milestones that did not happen. A design study says it is a design study. A single-maintainer project says so. (Axiom A9.)

## 4. Attributed

Every repository, package manifest, essay and page names Brandon Fox as author, with a personal e-mail. Contributions from others are attributed to their authors through [Developer Certificate of Origin](https://developercertificate.org/) sign-off on each commit.

## 5. Mine alone

Views, writing and code published here are Brandon Fox's own, produced on personal time and personal equipment. They represent no employer, current or former, and are not affiliated with, endorsed by, or derived from the work of any employer. Every code and writing surface carries this notice. (Axiom A8.)

## 6. Audited, then fixed

Principles 1 to 5 are checkable by script, run on a cadence, and a violation becomes a fix pull request within the next working session rather than a note. The script is [`scripts/validate_axioms.sh`](https://github.com/First-ADE/.github/blob/main/scripts/validate_axioms.sh); the axioms are in [`AXIOMS.md`](https://github.com/First-ADE/.github/blob/main/AXIOMS.md).

## Why open source

Open source is how I learned to build, and publishing the method rather than only the product is the clearest way I know to show how I think. I would rather be corrected in public than trusted in private. If you use any of this, no credit is required beyond the license; if you improve it, send the change back.
